## Preparación antes de entrar en sala

- Comprobar URL de Slidev y modo presentación a pantalla completa (tecla F).
- Abrir dos pestañas adicionales: web Three.js e Issues de GitHub.
- Preparar Github Mobile con sesión autenticada en ambos teléfonos.
- Verificar el acceso real a agentes de Copilot, Claude, Codex; los modelos elegibles de chat no son lo mismo.
- Tener creadas ramas o PRs de respaldo y capturas que estén **claramente etiquetadas** como preparadas.
- Validar la URL que codifica QR de Issues (crea la plantilla).
- Probar Wi-Fi de asistentes y red de ponentes, móvil Android y proyector.
- Identificar estado Worker y D1: si falta, la web es demo y las Issues no llenarán la galaxia en tiempo real.
- No ejecutar contribuciones externas arbitrarias; Issue → validación → objeto seguro.
- Revisar nombre/cargo/fotos y visibilidad de logos desde proyector real.
- Comprobar contraste, animaciones reducidas y navegabilidad por teclado.

## Plan B

1. Si falla Slidev, abrir la presentación web desde otro navegador (Chrome/Edge).
2. Si falla el iframe, abrir directamente la galaxia a pantalla completa.
3. Si falla el Worker, mostrar Issues reales y la galaxia como dos piezas independientes; no prometer tiempo real.
4. Si un agente tarda, mostrar su tarea en ejecución y un PR preparado etiquetado como respaldo.
5. Si falla la red, utilizar la versión PPTX anterior únicamente como apoyo visual, dejando claro que no es el entorno interactivo.
